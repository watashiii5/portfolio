Featured Thesis Project

QTime: Quantum-Inspired Optimization for College-Based Room Allocation in Bulacan State University College of Science

I served as the main developer and built the project end-to-end: a web app that helps the College of Science allocate rooms more efficiently by turning scheduling constraints (room availability, time slots, and conflicts) into an optimization problem and producing a practical schedule.

I designed and implemented the full stack using Next.js and TypeScript for the UI and application logic, Supabase for the database and backend services, and Python for experimentation and support scripts during development. I also handled styling with CSS, deployment, and continuous iteration with the help of AI tools.
