YUI AI Companion

AI companion web app inspired by Yui (Sword Art Online)

View Live Demo

Overview

YUI AI Companion is a simple chat-style experience where users can interact with an AI character. It focuses on a friendly, lightweight UI (character card + chat box) and aims to feel like a “companion” rather than a generic chatbot.

What I Built

This project integrates the Groq LLM API to generate responses and connects it to a web-based chat interface with message input and actions like sending and speaking messages.

Highlights

  • Character-first UI: simple companion card + chat panel layout.
  • Interactive chat: message input and send flow designed for quick back-and-forth.
  • AI responses: user prompts are sent to Groq, then rendered back into the conversation.
  • Deploy-ready: hosted on Vercel so it’s accessible as a live demo.

How It Works

A user message is submitted from the front-end, the app calls the Groq API to generate the assistant reply, and the response is displayed back in the chat UI.

Tech Notes

Front-end: HTML, CSS, JavaScript • AI: Groq API • Deployment: Vercel
