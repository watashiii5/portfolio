QTime Thesis Project

QTime: Quantum-Inspired Optimization for College-Based Room Allocation in Bulacan State University College of Science

View Live Demo

Overview

QTime is a scheduling and room-allocation web application for the College of Science. The goal is to help generate room assignments that reduce conflicts and make better use of available rooms and time slots. In our thesis, we explored a quantum-inspired optimization approach, but the output is practical and straightforward: a usable allocation plan based on real constraints.

My Role (Main Developer)

I was the main developer and built the system end-to-end. I handled the overall architecture, implemented the UI and core logic, connected the backend services, and iterated on the project until it worked reliably for real use cases. I also supported our development process with AI tools for faster iteration, debugging, and writing.

Tech Stack

Next.js, TypeScript, Supabase, Python, CSS (plus AI tools during development)
